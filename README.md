# GayaSeva - Yatri & Pilgrim Services Portal

Official repository for **GayaSeva** — comprehensive digital pilgrimage, Pandit booking, hotel/dharamshala stay, taxi & transport, and admin management portal for Gaya Ji.

## Features
- **30-Section Yatri Website**: Next.js 14, TailwindCSS, Framer Motion animations.
- **Login & Registration**: Unified role-based authentication for Yatris, Pandits, Drivers, and Hotels.
- **Admin Management Portal**: Real-time user management with full CRUD support.
- **Floating Assistants**: WhatsApp Enquiry & AI Yatri Assistant.

## Project Structure
- `frontend/website`: Yatri Pilgrim Customer Portal
- `frontend/admin`: GayaSeva Administrative Control Portal
